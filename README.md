# Realtor Clause Assistant

A conversational AI that helps BC realtors find the right BCFSA clauses for their contract of purchase and sale. Describe a scenario (e.g. subject to financing, tenant in the property, strata) and get the **actual clause wording** to copy into the contract.

**Knowledge source:** [BCFSA Clauses](https://www.bcfsa.ca/industry-resources/real-estate-professional-resources/knowledge-base/clauses/clauses).  
**Disclaimer:** The clauses and any suggestions from this assistant are for **educational use only** and do not constitute legal or other professional advice. Always refer to bcfsa.ca for the latest resources and consult your managing broker when in doubt.

## What it does

1. **Scrape** – Fetches the BCFSA clauses page and saves it in a structured format.
2. **Ingest** – Stores one chunk per clause in a vector database so each clause can be retrieved whole.
3. **Chat** – Realtors describe a scenario; the assistant recommends clause(s) and returns copy-paste-ready wording.

## Prerequisites

- Python 3.9+
- Node.js 18+ (for frontend)
- [OpenAI API key](https://platform.openai.com/api-keys)

## Quick start

### 1. Backend setup

```bash
cd bc-realtor-clauses
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` (or set environment variables) with:

- `OPENAI_API_KEY` – required for embeddings and the LLM.

### 2. Scrape BCFSA clauses

```bash
python scripts/scrape_bcfsa_clauses.py
```

This writes `knowledge_base/bcfsa_clauses.txt` with one clause per block (delimited by `---CLAUSE---`).

### 3. Ingest clauses into the vector database

```bash
python scripts/ingest_bcfsa_clauses.py
```

By default this **clears** the existing collection and ingests from `knowledge_base/bcfsa_clauses.txt`. Use `--no-clear` to add without clearing.

### 4. Run the backend

```bash
python -m backend.main
```

API: `http://localhost:8000`

### 5. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

App: `http://localhost:3000`

## Project layout

- `backend/` – FastAPI, RAG chain, embeddings, vector store, LLM client.
- `frontend/` – React chat UI (“Realtor Clause Assistant”).
- `knowledge_base/` – `bcfsa_clauses.txt` (generated by the scraper).
- `scripts/` – `scrape_bcfsa_clauses.py`, `ingest_bcfsa_clauses.py`.

This project uses a **separate** vector DB and collection from the original Agent app:

- `VECTOR_DB_PATH` defaults to `./chroma_db_realtor_clauses`
- `COLLECTION_NAME` defaults to `realtor_clauses`

## Configuration

In `backend/config.py` or via environment variables:

- `OPENAI_API_KEY` – required.
- `VECTOR_DB_PATH` – default `./chroma_db_realtor_clauses`.
- `COLLECTION_NAME` – default `realtor_clauses`.
- `LLM_MODEL`, `EMBEDDING_MODEL`, `TOP_K_RESULTS` – same as in the base Agent stack.

## BCFSA and educational use
